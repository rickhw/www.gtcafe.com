git

Rick Hwang
GTCafe Studio

寶石鑑定專家來公司分享 git 的心得～高老師開始就問：有沒人不知道 git 的？

我心裡想：恩，我在 git 還沒出來之前就知道了 #GIT 了，不是唬爛的，因為那是我的夢想呢，恩。。。 GIT 全名是：[Guitar Institute of Technology (GIT)][1] ，是美國 #洛杉磯音樂學院 ([Musicians Institute, MI][2]) 的其中一個系。有點像台灣的二技、四技，主修樂器就是吉他。現在台灣線上有名的一線吉他手，大概有六、七成，是在兩千年去留學回來的，另一批則是去 #百克里音樂學院（Berklee College of Music, 以爵士樂聞名）

IT 領域的 git 出現後，我疑惑了好久。。反正沒本錢去，玩玩另一種 git 也可以過過乾癮。。。 XDD

Rick Hwang
GTCafe Studio

#溝通品質 #Notes #白板 #線上異常處理

溝通過程的標準協議方法，包含 圖、文，提高 #溝通品質：

  • 黑色：現況、架構圖
  • 藍色：問題點 (Story)、討論、蒐集資料
  • 綠色：暫解 (Short term)、正解、未來 Solution
  • 紅色：Actions + People + Acceptance

確認溝通的過程，本身是有品質的
